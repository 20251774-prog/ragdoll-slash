How to play with friends

  1. The host turns on their phone's Wi-Fi hotspot. No internet or data is needed.
  2. Friends connect to the host's hotspot Wi-Fi.
  3. Everyone opens Ragdoll Slash.
  4. The host taps Host a game. A code appears.
  5. A friend taps Join a game and scans the host's code with the camera.
  6. The friend's phone then shows its own code. The host taps Scan friend's code and scans it.
  7. For more players (up to 4), the host taps Add another player and repeats steps 5 and 6.
  8. The host taps Start fight.

If the camera does not work, use "Copy my code as text" and send it (for example by Bluetooth or a message), then use "Paste".

Controls

Phone: hold the phone sideways. Left side: ◀ ▶ to move. Right side: Slash to swing (tap again quickly for a combo), Jump, Block (hold, face the enemy), Dash, Swap to change weapon.

Guns and bow: the big button becomes Fire. Tap it to shoot at the nearest enemy, or hold it and drag to aim, then let go. The rifle keeps firing while you hold. Hold to draw the bow, then let go. Reloading is automatic.

Keyboard: A / D or arrows move, W / Space / ↑ jump, J attack or fire, K block, L or Shift dash, Q swap, R reload, Esc pause. The mouse aims and clicks to fire.

Armour soaks up damage until it breaks off. Then that body part gets hurt much more. Heavy armour is slower. Hit the head for extra damage. First to 3 round wins takes the match.
